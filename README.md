# 道草45 Studio

> **Version 1 / アプリ表示 v0.00.1**<br>
> 思考を書き、寄り道を分類し、その過程を映像として残すためのWindows向け制作ツールです。

![道草45 Studio ロゴ](public/app-logo.png)

## 概要

道草45 Studioは、無限キャンバスへ考えを書き出す「思考モード」と、思考の広がりをスタンプで振り返る「分析モード」を備えたElectronアプリです。

プロジェクトは独自の`.m45`形式で保存できます。キャンバスとマイク音声は録画でき、従来版AviUtlで扱いやすい固定フレームレートのAVIとして保存します。

## Version 1でできること

### 思考モード

- 筆圧対応のペン描画
- 触れた部分だけを消す部分消去
- パン、ズーム、Undo、Redo
- 色とサイズの変更、ユーザー定義プリセット
- 表示・非表示を切り替えられるレイヤー

### キャンバス背景

- 白、黒、紙色
- 無地、ドット、罫線、方眼
- 模様の間隔変更
- パンとズームに追従するワールド座標基準の模様

### 分析モード

- テーマスタンプとユーザー定義スタンプ
- スタンプ名、色、サイズの編集
- スタンプテンプレートの保存と読込
- スタンプ箱のドラッグ移動
- 道草値の表示切替
- スタンプの使用割合を確認する「集計」
- 動画の最後に提示できる「今回のまとめ」
- まとめカードへのペン入力
- まとめカードのPNG出力

道草値は、分類用スタンプのワールド座標全体から、広がり、多方向性、スタンプ数を使って0〜45で算出します。ズーム率やカメラ位置には影響されません。

### 録画とAVI出力

- キャンバスとマイク音声の同時録画
- 表示Canvasを直接録画し、ツールバーや各種操作パネルを除外
- 録画中も表示Canvasの内部解像度を変更せず、通常時と同じDPIで描画
- 720p、1080p、1440p、4K
- 30 fps、60 fps
- 4、8、12、20 Mbps
- AVI画質：最高画質、標準（既定）、軽量
- 音声入力デバイスの選択
- 録画前のリアルタイムdBFS・ピークレベルモニター
- フィルター適用後音声のヘッドホンモニターとモニター音量調整
- 入力ゲイン（-30〜+30dB）、ハイパス、3バンドEQ
- コンプレッサー、リミッター、OS／ブラウザのノイズ抑制
- 音声レベルと録画時間の表示切替
- 内部収録したWebMを固定30/60fpsへ正規化
- Motion JPEG映像と48kHz PCMステレオ音声を1本にまとめたAVI保存
- 従来版AviUtlの標準入力およびL-SMASH Worksを想定した編集用形式

内部WebMを高品質MJPEGのAVIへ変換して保存します。Windows標準プレイヤーがMJPEGのフルレンジを白側へ誤展開するのを避けるため、動画はリミテッドレンジの4:2:2として出力します。AVI画質は最高画質（q1）、標準（q3）、軽量（q5）から選択でき、既定は容量と画質のバランスを取った標準です。AviUtl／L-SMASH Worksでも読み込める形式です。

録画映像はキャンバス本体から直接取得します。録画専用Canvasへの毎フレーム再描画は行わないため、ストローク数が増えた場合の重複描画負荷を抑えています。表示Canvasは録画開始時にもリサイズせず、保存時に高品質縮小して選択した標準解像度へ変換します。Canvasと動画の縦横比が異なる場合は、白帯や歪みを避けるため中央基準で端を切り取ります。

録画開始時は自動的にフルスクリーンへ移行し、Canvasを画面全体へ広げます。メニューとツールバーはCanvas上の操作レイヤーとして表示されますが、動画には含まれません。録画停止後は、録画前がウィンドウ表示だった場合のみ元の表示へ戻ります。

RECを押した時点で保存先を選択し、FFmpegが完成AVIを指定先へ直接書き込みます。録画中にWebMチャンクをMainプロセスへ順次送り並行変換するため、Rendererに録画全体を保持せず、停止後の巨大ファイルコピーも発生しません。保存先選択をキャンセルした場合は録画を開始せず、録画失敗や破棄時には未完成ファイルを削除します。

長時間録画では、圧縮済みWebMを復旧用素材として保存先へ一時退避します。通常のAVI変換が完了すれば自動削除されます。変換の遅延やメモリ不足で録画中のFFmpegが停止した場合は、録画終了後に復旧用素材から同じ解像度・画質でAVIを自動生成します。復旧変換にも失敗した場合はWebM素材を削除せず、エラーメッセージに保存場所を表示します。

Canvasは内容が変わらない間、ブラウザから映像フレームが出力されない場合があります。長い静止区間を停止時にまとめて複製するとメモリを圧迫するため、録画中は一定間隔で映像フレームを明示的に取得します。描画時のフレームレートやAVIの解像度・画質は変更しません。

高DPI環境でCanvas内部が4K相当になる場合も、FFmpegでは先に選択した出力解像度へ縮小してから固定フレームレート化します。1080p出力時はフレーム補間を1080p上で行うため、4Kフレームを複製する場合よりメモリ使用量を抑えられます。

音声フィルターはOBSの同名設定と同じdB、Hz、比率、ms単位を使用するため、数値を転記できます。ただし、ブラウザ提供のノイズ抑制はOBSのRNNoise／Speexとアルゴリズムが異なり、サイドチェーン・ダッキングにも対応していません。録画前に「レベルモニター」で確認し、通常音声が-18〜-6dBFS、ピークが-3dBFS前後に収まるよう調整してください。

### プロジェクト

- 新規作成、開く、保存、名前を付けて保存
- `.m45`形式へのキャンバス、カメラ、背景、レイヤー、スタンプ設定の保存
- メニューとキーボードショートカットによる操作

## 動作環境

- Windows 11
- Node.js 22系を推奨
- npm
- マイク
- ペンタブレットまたは液晶ペンタブレットを推奨

基準表示は1920×1080です。Windows表示倍率100%および125%を想定しています。

## セットアップ

```powershell
npm install
npm start
```

## テスト

```powershell
npm test
npm exec tsc -- --noEmit
```

## ビルド

アプリをパッケージ化します。

```powershell
npm run package
```

インストーラーと配布用アーカイブを生成します。

```powershell
npm run make
```

## 主なショートカット

| 操作 | ショートカット |
|---|---|
| 新規作成 | `Ctrl+N` |
| 開く | `Ctrl+O` |
| 保存 | `Ctrl+S` |
| Undo | `Ctrl+Z` |
| Redo | `Ctrl+Y` |
| 録画開始・停止 | `R` |
| パン | `Space`を押しながらドラッグ |
| ズーム | マウスホイール |

## プロジェクト構成

```text
assets/                         配布用アイコン、ビルド時に取得するLGPL版FFmpeg
public/
├─ app-logo.png                 アプリ内ロゴ
└─ vendor/EBML.min.js           WebMメタデータ処理
src/
├─ layers/                      レイヤーUI
├─ recording/RecordingManager.ts
├─ review/                      分析、道草値、スタンプ箱
├─ shared/                      プロジェクト形式と共通型
├─ whiteboard/Whiteboard.tsx    キャンバスと主要UI
├─ main.ts                      Electronメインプロセスとファイル保存
└─ preload.ts                   Renderer向けAPI
```
